2. КРИТИЧЕСКИЕ БАГФИКСЫ (относительно fork XeonDead)
================================================================================

2.1. Notify.java
  Было: в show() создавался пустой NotificationCompat.Builder — пустые
        foreground/уведомления, нестабильный FGS.
  Стало: корректный Builder с CHANNEL_ID, канал уведомлений,
         ServiceCompat.startForeground(..., FOREGROUND_SERVICE_TYPE_DATA_SYNC).

2.2. DnsClient.java
  Было: InetSocketAddress.toString() → строки вида "/1.1.1.1:53", DNS ломался.
  Стало: используется getHostAddress() / корректный host:port.

2.3. WifiUtils.isEnabled()
  Было: вместо «радио Wi‑Fi включено» проверялся SupplicantState
        (association) → ложные «Wi‑Fi выключен».
  Стало: WifiManager.isWifiEnabled(); отдельно добавлен isAssociated().

2.4. BackendWorker.java
  Было: new Constraints(NetworkType.UNMETERED, ...) — хрупко/ломается
        на новых WorkManager.
  Стало: Constraints.Builder; ошибки старта не валят приложение.

2.5. Краш при открытии на Android 15/16
  Было: Theme.Holo.*, registerReceiver без флагов, жёсткий init в Application.
  Стало:
    - темы DeviceDefault (+ values-v35);
    - Util.registerReceiver(..., EXPORTED / NOT_EXPORTED);
    - MosMetroApp: try/catch вокруг Logger / WorkManager / Sentry.

3. ANDROID 12–16 СОВМЕСТИМОСТЬ
================================================================================

Манифест / runtime:
  - android:exported для Activity/Receiver с intent-filter
  - POST_NOTIFICATIONS + запрос при старте Settings (API 33+)
  - FOREGROUND_SERVICE + FOREGROUND_SERVICE_DATA_SYNC
  - foregroundServiceType="dataSync" (ConnectionService, ReceiverService)
  - Util.startService → ContextCompat.startForegroundService
  - PendingIntent всегда FLAG_IMMUTABLE (Util.pendingFlags)
  - ACCESS_FINE_LOCATION (SSID на новых Android, иначе <unknown ssid>)
  - ACCESS_BACKGROUND_LOCATION в манифесте
  - WRITE_EXTERNAL_STORAGE ограничен maxSdkVersion=28
  - Ранний startForeground в ConnectionService.onStartCommand

Сеть / cleartext (captive portals):
  - network_security_config.xml: HTTP разрешён для wi-fi.ru,
    welcome.wi-fi.ru, auth.wi-fi.ru, gowifi.ru, mos.ru и связанных доменов
  - usesCleartextTraffic=true (для порталов авторизации)

Edge-to-edge / insets (Android 15+ / targetSdk 36):
  - SystemBarUtils: setDecorFitsSystemWindows(false) + ручные insets
  - ActionBar (action_bar_container): topMargin = statusBar/cutout
  - content паддится только если реально уезжает под ActionBar
  - фон content = bgSecondary (без «зелёного окна» на весь экран)
  - re-apply после onResume / replaceFragment / back stack
  - Settings / Debug / Feedback; values-v35 opt-out edge-to-edge

Меню ручного выбора сетей (2.8.1):
  - NetworksFragment: список SSID из Provider.SSIDs (транспорт / город /
    МТС / прочее) + «текущая сеть» / force login
  - Preference «Сети Wi‑Fi» / «Wi‑Fi networks» → ручной вход + DebugActivity
  - ConnectionService.EXTRA_SSID для лога / fallback display SSID
